Popup UI는 React로 구성하고, 알림 예약은 chrome.alarms로 처리했습니다. 사용자 설정과 일일 스트레칭 기록은 Local Storage에 저장해 서버 없이 동작하도록 만들었습니다.

Troubleshooting

트러블슈팅

어떤 문제가 있었고 어떻게 해결했는가

Problem

알림 On/Off, 완료 기록, 다음 알림 시간이 서로 어긋나면 사용자가 앱을 신뢰하기 어려웠습니다.

Approach

서버 없이도 설정과 기록이 유지되는 Local-first 구조로 정리했습니다.

Action

완료 버튼 클릭 시 기록 저장과 다음 알림 예약을 함께 처리했습니다.

Result

팝업을 다시 열어도 알림 설정과 일일 완료 기록이 유지되도록 만들었습니다.
