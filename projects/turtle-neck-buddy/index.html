Overview

작업 흐름을 방해하지 않는 건강 습관 도구

기간2026.07

역할Product Owner / AI-assisted Developer

핵심 스택React 18, TypeScript 5, Vite 5, Manifest V3

저장 방식Local Storage 기반 Local-first

집중 중에는 스트레칭 시점을 놓치기 쉽고, 강한 알림은 오히려 사용을 중단하게 만듭니다. Turtle Neck Buddy는 사용자가 알림 간격과 완료 기록을 직접 관리하고, 30초 스트레칭 가이드를 따라 할 수 있게 만든 도구입니다.

Architecture

Manifest V3 기반 모듈 구조

Popup UI, Service Worker, Chrome APIs, Local Storage를 역할별로 분리했습니다. 서버 없이 동작하도록 설계해 개인정보 전송 부담을 줄이고, 설치 즉시 사용할 수 있게 했습니다.

Technical Challenges

핵심 기술 문제

알림 피로도

사용자가 작업을 중단하지 않도록 알림 간격과 즉시 스트레칭/나중 알림 행동을 분리했습니다.

상태 유지

확장 프로그램 재실행 후에도 알림 설정과 일일 완료 횟수가 유지되도록 로컬 저장소에 상태를 저장했습니다.

MV3 제약

Service Worker 특성상 항상 살아 있지 않으므로 chrome.alarms 기반으로 일정 관리를 구성했습니다.

PAAR

알림과 완료 기록의 상태 동기화

Problem알림 On/Off, 완료 기록, 다음 알림 시간은 서로 연결되어 있어 상태가 어긋나기 쉽습니다.

Decision사용자 설정과 완료 기록을 Local Storage에 저장하고, 알림 트리거는 chrome.alarms로 위임했습니다.

ImplementationPopup UI는 저장된 상태를 읽어 화면을 갱신하고, 완료 버튼 클릭 시 기록 저장과 다음 알림 예약을 함께 처리합니다.

Result서버 없이도 알림 설정과 일일 완료 기록이 유지되어 간단하고 가벼운 사용 경험을 만들었습니다.

Testing

검증 방식

  • 알림 On/Off 변경 후 Popup UI와 저장 상태가 일치하는지 확인
  • 완료 버튼 클릭 시 일일 스트레칭 횟수와 진행률이 갱신되는지 확인
  • 확장 프로그램 재실행 후 Local Storage 기반 설정이 유지되는지 확인

Retrospective

회고와 개선 방향

작은 생산성 도구일수록 기능보다 사용 지속성이 중요하다는 점을 배웠습니다. 이후에는 사용자의 업무 시간대와 휴식 패턴에 따라 알림 강도를 조절하고, 통계 화면을 더 정교하게 개선하고 싶습니다.
